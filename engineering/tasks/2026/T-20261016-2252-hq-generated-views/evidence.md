    - git ignores these files, so the build disagrees with what the repo actually holds;
    - a Finder visit or an open editor breaks the build on the owner's Mac;
    - the error surfaces as the hq view being broken.
  - **Recommended exact rule:** walk `git ls-files --cached --others --exclude-standard`, which is every tracked file plus every untracked file that is not ignored. It drops OS and editor debris through the repo's own .gitignore, with no hand-made list of names. A pure "tracked only" rule would let an uncommitted stray file through, so I do not recommend it.
