# Acceptance: sandbox gets the Dhan instrument master

1. **Seed copies read-only.** A test builds a fake live root that holds `data/alto_data/workspace/u1/system/dhan_instruments.json` (with all six keys and `date`). It calls `seed_instrument_master(live_root, sandbox_root, "u1")`. The sandbox file is byte-identical, and the live file's bytes and mtime are unchanged. The test patches `requests.get` and `DhanInstrumentMapper._fetch_and_cache` to raise, and neither is called.
2. **Seed raises before the worktree exists.** `create(..., seed_masters=("nobody",))`, with no live file, raises `FileNotFoundError` naming the live path. No worktree and no sandbox root are created (the same order as the `--seed-index` pre-check). A live file without `date`, or without any one of the six keys, raises naming the path and the missing key.
3. **CLI flag.** `python -m backend.config.new_sandbox_worktree --help` lists `--seed-instrument-master`. A test calls `main()` with the flag on a temporary live checkout, and the sandbox file exists afterwards.
4. **Freshness raises exactly.** With a stored master dated 2026-10-16: `load_stored(as_of=date(2026,10,16))` and `load_stored(as_of=date(2026,10,1))` load. `load_stored(as_of=date(2026,10,17))` raises, and the message contains the path, `2026-10-16` and `2026-10-17`. A master with no `date` raises. `load_stored()` with no `as_of` is a `TypeError`, because the argument has no default.
5. **Reader passes its date.** A test of `broker_factory/daily_series` in sandbox mode with a seeded master: a series whose `end` is on or before the master date resolves `get_exchange` for an NSE symbol. A series whose `end` is after the master date raises the check-4 error. `git grep -n "load_stored()" -- backend/executor` is empty, so every caller passes `as_of`.
6. **No network in the sandbox path.** The sandbox `daily_series` tests from check 5 pass with `socket.socket.connect` patched to raise.
7. **Pilot unblocked (dry).** On this machine, `python -m backend.config.new_sandbox_worktree T1300-qa --seed-index SHILPAMED --seed-instrument-master scienceamit1` succeeds. In that worktree, `python -c` builds the sandbox daily series for SHILPAMED with an `end` no later than the master date and reads its exchange without `FileNotFoundError`. No LLM run. QA removes the worktree and sandbox afterwards.
8. **Suite.** No new failure against a sandbox-worktree base (`comm -23 new base` is empty). `stores/tests/test_boundaries.py` passes, and so does the existing `new_sandbox_worktree` test. The entry points import: main_cockpit, app_factory, e2e.lanes, harness and new_sandbox_worktree.
9. No Dhan call, no LLM run and no network during dev or QA. Refreshing the live master is the owner's call.
