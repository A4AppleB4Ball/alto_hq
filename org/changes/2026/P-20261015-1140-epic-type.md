## Problem

Validation, orchestration and data storage each need a plan of several
stories, but creating a task per story up front makes work the owner must
build and verify one by one. There was no place for a plan that is not yet
tasks.

## Change

New item type `E` (epic, `org/epics/<year>/E-….md`, schema epic/v1): a goal
and stories as one-liners. A story becomes a task only when it is next.
