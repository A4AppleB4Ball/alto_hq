# Completeness definition (draft for owner approval)

Owner rules, 2026-10-16. Feeds the first follow-up of T-20261015-1058-dagster-spike. Not a task; the owner creates it.

## Principle
One function in `backend/lib/` (doc in `backend/lib/docs/`) computes a company's completeness state. Dagster, the rebalance proposal gate and e2e import it; none re-derives it. It reads stores as they are (no capture, no network). It returns a state and a reason, never only pass/fail, and records the fingerprint of what it read and its own version.

## Company level
- **Not initiated:** no chain start (`lib/chain_start`: neither the FY26 annual nor a Q1 FY27 document). Expected: no stance. Not a failure and not "complete".
- **Stance without chain start:** violation (a stance that should not exist).

## Quarter level (quarters in the chain)
Which quarters can have documents comes from `raw/results_calendar/due.company_due_quarters` (the one rule); labels convert through `lib/quarter_policy`.

| State | Condition | Blocks the stance |
|---|---|---|
| Final | has PPT and/or transcript, and a newer quarter holds any document | only if analysis is Missing or Stale |
| Open | newest quarter with documents, one of PPT/transcript missing | no; analysed with what exists; **stays open until the next quarter's data comes in** |
| Not released | no documents, a later quarter holds some | no |
| Due, nothing in | due per calendar, no document, no later quarter holds one | yes (gap) |
| Expected | latest quarter, meeting date in the future | no |
| Unknown | no meeting on record | no, but reported as "no meeting on record" |
| Missing | has documents, no valid analysis | yes |
| Stale | a backdated or new document makes the stored analysis older than the quarter's current document set | yes, until re-analysed and every later chain link rebuilt |

## Beyond quarters
- Every document the index knows (announcements, quarterly, annual) is extracted, analysed, and consumed by the stance chain in sequence.
- A stance input is an analysis key, never raw quarterly data; checked structurally from the stance record's inputs.
- Duplicate BSE/NSE filings (15-page cut) are harmless: identity is the quarter, not the document.

## Known limits (reported on the result, not hidden)

- Stale calendar store: reported as its own state.
- Document types and exchange-parsed quarterly data: future scope (SLM document intelligence).
